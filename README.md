# Nasik Metaldust MIS

Management Information System for Nasik Metaldust Pvt Ltd, Plant P-65 (Finance & Accounts).

* `index.html` — the app (same screens, design and sign-in as the Claude version).
* `firebase-config.js` — the link to this company's Firebase project.

Figures, logins and backups are stored in Firebase (Authentication + Cloud Firestore), not in this repository.
Access is controlled by the Firestore security rules and each person's login.
